# Физика и математика SpektroLab

## 1. Закон Планка

Спектральная плотность энергетической яркости абсолютно чёрного тела:

```
               2·h·c²            1
B(λ, T) = ─────────────── · ─────────────
              λ⁵          exp(h·c / (λ·k·T)) − 1
```

- `h = 6.62607015e-34` Дж·с
- `c = 299792458` м/с
- `k = 1.380649e-23` Дж/К
- λ — в метрах, T — в кельвинах.

В коде (`core/planck.py`) длина волны задаётся в нанометрах, абсолютный масштаб
не важен: при подгонке он уходит в коэффициент `a`.

## 2. Подгонка температуры

Модель: `I(λ) = a · P(λ, T) / max P(λ, T) + b`, где `P` — закон Планка.

При **фиксированной T** модель линейна по `a` и `b`:

```
I = a·p(T) + b          →  МНК: [a, b] = lstsq([p(T), 1], I)
```

Поэтому остаётся одномерная задача `min_T SSE(T)`:

1. грубая сетка `T` (логарифмическая, 320 точек по умолчанию),
2. уточнение минимума методом золотого сечения,
3. расчёт `R²`, `RMSE` и ковариационной матрицы.

Погрешность температуры:

```
σ² = SSE / (n − 3)
J  = [∂I/∂T, ∂I/∂a, ∂I/∂b]
cov = σ² · pinv(JᵀJ)
ΔT = √cov[0,0]
```

Это даёт тот же порядок точности, что `scipy.optimize.curve_fit`, но без SciPy
и без риска «убежать» в соседний локальный минимум.

### Практические замечания

- Рабочий диапазон по умолчанию: **700–12000 К**.
- Края спектра, где сенсор шумит или обрезан, лучше исключать (`wl_range`).
- Для светодиодов и газоразрядных ламп закон Планка не выполняется: `R²` будет низким,
  и это нормальный результат — источник не является чёрным телом.
- Светодиод/люминесцентная лампа: фит может формально «сойтись», поэтому смотрите на `R²`
  и наличие сильных линий.

## 3. Законы Вина и Стефана — Больцмана

```
λmax · T = b = 2.897771955e-3 м·К
j* = σ·T⁴,  σ = 5.670374419e-8 Вт/(м²·К⁴)
```

Для лампы накаливания при 3000 К максимум приходится на **966 нм** — в ближнем ИК,
который глаз не видит, но видит камера без ИК-фильтра. Это хорошая демонстрация
на уроке: «почему лампочка горячая, а свет кажется жёлтым».

## 4. Калибровка

Дешёвая оптика и сенсор дают нелинейную связь «пиксель → длина волны»:

```
λ(p) = c₀ + c₁·p + c₂·p² + …
```

Коэффициенты находятся МНК по эталонным линиям (`core/calibration.py`). Контроль:

- RMS остатков < 1 нм — хорошая калибровка;
- максимальная ошибка < 2 нм;
- линии должны монотонно расти или убывать вместе с пикселем.

Рекомендуемые источники: ртутная лампа (404,66 / 435,83 / 546,07 / 576,96 / 579,07 /
611,60 нм), неоновая лампа (много линий 585–717 нм), натриевая лампа (589,0/589,6 нм).

## 5. Поиск и описание линий

`core/peaks.py` реализует аналог `scipy.signal.find_peaks`:

- локальные максимумы (`y[i] > y[i−1]` и `y[i] ≥ y[i+1]`);
- **prominence** — высота над ближайшей седловиной;
- фильтр по минимальному расстоянию (в отсчётах), при конфликте остаётся более высокий пик;
- центр линии уточняется параболой по трём точкам;
- FWHM — ширина на половине высоты с линейной интерполяцией crossings;
- площадь — интеграл в пределах FWHM.

Распознавание (`core/lines.py`) сравнивает измеренные λ с табличными в пределах допуска
(по умолчанию 2 нм) и возвращает ошибку `λ_изм − λ_табл`.

## 6. Оптика прибора (для конструкции)

Угол дифракции для пропускающей решётки с периодом `d`:

```
sin θ = sin α + m·λ/d,   m = +1, α — угол падения
```

Угловая дисперсия:

```
dθ/dλ = 1 / (d·cos θ)
```

Линейная дисперсия на сенсоре (объектив с фокусным `f`, камера сфокусирована на бесконечность):

```
dy/dλ = f / (d·cos³θ)
```

Оценка оптического разрешения по щели шириной `w` и коллиматору с фокусным `F`:

```
Δλ ≈ (w / F) / (dθ/dλ) = w·d·cos θ / F
```

Для `w = 0,05 мм`, `F = 40 мм`, `d = 1/600 мм`, `θ ≈ 25°`: `Δλ ≈ 1,9 нм`.
При пикселе 2,8 мкм и `f = 3,6 мм` получается ≈1 нм на пиксель — программная
интерполяция даёт шаг лучше 1 нм, но оптическое разрешение остаётся ~2 нм.
Это честная характеристика DIY-схемы, её и нужно указывать в паспорте.

Подробный расчёт и допуски — в `hardware/optics.py` и `hardware/README.md`.
