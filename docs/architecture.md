# Архитектура SpektroLab 0.2

## Цели

- **Работает без железа.** Ядро и тесты не требуют камеры, PySide6 и SciPy — только NumPy.
  Поэтому физику можно проверять в CI, а интерфейс — отлаживать на симуляторе.
- **Один источник истины.** Формулы, калибровка и обработка живут в `core`, а CLI и GUI
  лишь вызывают их. Нет дублирования физики между режимами.
- **Честные измерения.** Каждый результат сопровождается R², RMSE, ΔT и метаданными,
  протокол воспроизводим.
- **Расширяемость.** Новый источник кадров — это класс `Camera`; новый формат отчёта —
  метод `Measurement`; новые линии — словарь в `core/lines.py`.

## Ключевые решения

| Решение | Почему |
|---|---|
| Без SciPy | Меньше зависимостей, проще установка в школе, детерминированные тесты. Фит реализован как 1D-поиск + аналитический МНК. |
| `numpy` как единственная жёсткая зависимость | Ядро и CLI ставятся в любом учебном классе. |
| Симулятор в составе пакета | Демо и тесты без камеры; учитель может показать опыт на любом ноутбуке. |
| Ленивый импорт OpenCV/PySide6 | `import spektrolab` не падает, если GUI-зависимостей нет. |
| Полиномиальная калибровка | Дешёвая оптика даёт нелинейную дисперсию; степень 2 обычно снижает RMS до < 1 нм. |
| Протокол как Markdown | Читается человеком, вставляется в Word/Google Docs, не требует генератора PDF. |
| Погрешность T из ковариационной матрицы | Учитель видит не «магическое число», а интервал — это часть методики. |

## Форматы данных

### Калибровка (`*.json`)

```json
{
  "format": "spektrolab.calibration",
  "version": 1,
  "coefficients": [340.0, 0.68, 0.00012],
  "pixel_count": 1024,
  "rms_nm": 0.42,
  "max_error_nm": 0.9,
  "points": [{"pixel": 100.0, "wavelength_nm": 435.83, "residual_nm": -0.1}],
  "device": "spektrolab-usb-001",
  "created_at": "2026-11-22T18:00:00"
}
```

λ(p) = c₀ + c₁·p + c₂·p² + …

### Измерение (`*.json`)

Содержит формат, время, прибор, оператора, массивы λ и интенсивности, результат фита,
найденные линии и калибровку. Читается `Measurement.load_json()`.

### CSV

- `Spectrum.save_csv()` — `wavelength_nm;intensity`.
- `Measurement.save_csv()` — `wavelength_nm;intensity;planck_fit` (если фит есть).

## Тестирование

- `tests/` — 60 тестов на `unittest`: планк, фит, обработка, калибровка, пики, линии,
  протокол, симулятор, CLI.
- `spektrolab selftest` — быстрая проверка на живой машине (без тестового фреймворка).
- CI (`.github/workflows/ci.yml`) гоняет тесты и selftest на Python 3.11.

## Точки расширения

1. **Новый прибор.** Реализовать `Camera` (`open/read/close`) и передать в GUI.
2. **Другой формат калибровки.** Добавить загрузчик в `Calibration`.
3. **База линий.** Расширить `REFERENCE_LINES`.
4. **Новый отчёт.** Добавить метод `Measurement.to_pdf()` (matplotlib) или HTML.
5. **USB-протокол.** Заменить `OpenCVCamera` на прямое чтение сенсора через serial/HID.
