# Планы развития

## v0.3 — «прибор как продукт»

- [ ] Прошивка/протокол USB-модуля: прямое чтение сенсора без OpenCV, фиксированная экспозиция.
- [ ] Автоматическая экспозиция и контроль пересвета по кадру.
- [ ] Мастер калибровки в GUI: пошаговый с выбором эталонных линий и подсказками.
- [ ] Шаблоны лабораторных работ: «Тепловое излучение», «Линейчатые спектры», «Закон Вина».
- [ ] PDF-протокол (matplotlib) с графиком, таблицами и подписью.
- [ ] Сборка установщика Windows (`msi`) и AppImage для Linux.

## v0.4 — данные и сообщество

- [ ] База спектров источников (лампа накаливания, ЛДС, LED, солнце) с поиском.
- [ ] Сравнение измерений: наложение нескольких спектров, разностный спектр.
- [ ] Облачная синхронизация протоколов (опционально, с согласием пользователя).
- [ ] Веб-версия просмотра протоколов (без измерения).
- [ ] Английская локализация интерфейса и методичек.

## v0.5 — измерения

- [ ] Абсолютная фотометрическая калибровка (опорный источник).
- [ ] Измерение спектров пропускания/поглощения с кюветным отсеком.
- [ ] Оценка цветовой температуры и CCT по спектру.
- [ ] Автоматическое распознавание типа источника (чёрное тело / линии / LED).

## Идеи на будущее

- Мобильное приложение-компаньон (Android) для съёмки спектра через камеру телефона.
- Открытый каталог методичек от учителей (community-driven).
- Интеграция с лабораторными журналами школ.
