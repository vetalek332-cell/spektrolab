# Исходный прототип (v0.1)

`analyzer_pro.py` — первый рабочий прототип «Анализатор спектра PRO v4.0» (≈2 500 строк):
PySide6 + matplotlib + OpenCV + SciPy в одном файле. Он умеет подключать веб-камеру,
строить спектр, подгонять закон Планка, искать пики, записывать динамику и сохранять данные.

Файл сохранён **для истории и сверки**: новая версия (v0.2) разложена на пакет `spektrolab`
и не требует SciPy. Прототип не поддерживается и оставлен как референс.

Запуск (нужны PySide6, matplotlib, opencv-python, scipy):

```bash
python legacy/analyzer_pro.py
```

Чем v0.2 отличается:

| | `Beta.py` (v0.1) | `spektrolab` (v0.2) |
|---|---|---|
| Структура | один файл | пакет с ядром, CLI, GUI, тестами |
| Зависимости | numpy, scipy, opencv, PySide6, matplotlib | numpy; GUI — опционально |
| Подгонка Планка | `scipy.optimize.curve_fit` | МНК + золотое сечение, ΔT из ковариации |
| Калибровка | линейная по ROI | полином 1–3 степени по линиям, JSON |
| Тесты | нет | 60 unit-тестов + `selftest` |
| Работа без камеры | нет | симулятор прибора |
| Протокол | CSV/PNG | JSON + CSV + Markdown |
| Кроссплатформенность | Windows-ориентирован | Windows/Linux/macOS |
