# Changelog

Все заметные изменения проекта. Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — по [SemVer](https://semver.org/lang/ru/).

## [0.3.0] — 2026-11-22

### Добавлено

- **3D-модель**: генератор печатных STL без OpenSCAD (`hardware/cad/build_stl.py`):
  SDF + marching tetrahedra, сварка вершин, согласование ориентации, зашивание дыр,
  проверка замкнутости и объёма. 6 деталей: корпус, крышка, кассета щели, рамка
  решётки, оправа коллиматора, кронштейн камеры.
- Превью модели и карточка деталей (`hardware/cad/render_preview.py`, z-buffer
  рендер на Pillow, без 3D-библиотек).
- Питч-дек и таблица заявки в `docs/pitch/`.
- Печатная адаптация модели: нахлёсты 0,5 мм, светоловушки 2 мм, кольцо линзы 1,8 мм,
  убрана цековка 0,35 мм — все детали герметичны на сетке 0,8–1,4 мм.

### Изменено

- Версия пакета — 0.3.0.

## [0.2.0] — 2026-11-22

### Добавлено

- Модульное ядро `spektrolab.core` вместо одного файла-прототипа:
  спектр, физика Планка, подгонка, обработка кадра, калибровка, пики, линии, протокол.
- Подгонка по закону Планка **без SciPy**: линейный МНК по амплитуде и смещению
  при фиксированной T + одномерный поиск (сетка и золотое сечение) + оценка
  погрешности температуры по ковариационной матрице.
- Калибровка полиномом степени 1–3 по эталонным линиям, сохранение в JSON,
  контроль RMS и выход за диапазон.
- Поиск линий без SciPy: локальные максимумы, prominence, FWHM, площадь.
- Таблицы эталонных линий Hg, Na, Ne, H, He, Cd, лазерных диодов и распознавание.
- Протокол измерения: JSON, CSV с кривой Планка, Markdown-отчёт.
- Симулятор прибора и виртуальная камера — приложение и тесты работают без железа.
- CLI (`spektrolab selftest|simulate|analyze|calibrate|peaks|calibration-info|linear-calibration|ui`).
- Графический интерфейс на PySide6 + matplotlib: измерение, калибровка, линии, протокол.
- Конструкция USB-спектрометра: оптический расчёт, OpenSCAD-модель, BOM, сборка, чертёж.
- 60 unit-тестов на numpy, самопроверка `spektrolab selftest`.
- CI (GitHub Actions): тесты и самопроверка на Python 3.11.

### Изменено

- Прототип `Beta.py` (≈2 500 строк, PySide6 + SciPy + OpenCV в одном файле) разложен
  на пакет; исходник сохранён в `legacy/analyzer_pro.py` для истории.
- Диапазон прибора и ПО: 340–1050 нм вместо 390–1100 нм (как у аналогов класса
  USB-спектрометров 340–1050 нм).

### Исправлено

- Корректная обработка шумов и постоянного фона при подгонке Планка.
- Калибровка не принимает немонотонные пары «пиксель → длина волны».
- CLI не падает на кодировке консоли Windows (CP1251/CP866).

## [0.1.0] — 2026-11-16

### Добавлено
